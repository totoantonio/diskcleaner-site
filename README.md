# DiskCleaner Website

Official marketing website for **DiskCleaner** — a minimal, privacy-first macOS cleaning utility designed to safely recover storage without complexity.

This site communicates DiskCleaner’s core philosophy:

> Clean your Mac. Keep what matters.

---

## ✨ Overview

The DiskCleaner website is a lightweight, Apple-inspired landing experience built to showcase:

- Core product capabilities
- Zero-Decision Cleaning concept
- Product interface preview
- Feature breakdown
- Pricing and download entry point

The design emphasizes clarity, motion restraint, and content hierarchy consistent with modern macOS product marketing.

---

## 🚀 Features

### 🎯 Interactive Reveal System
- IntersectionObserver-based reveal animations
- Theme-aware re-initialization
- Smooth progressive content entrance

### 🌗 Dynamic Theme Engine
- Light / dark mode toggle
- CSS variable driven design system
- Instant UI state switching

### 🧠 Structured Product Narrative
- Hero positioning
- Statistics band
- Zero-Decision cleaning showcase
- Interface mockup section
- Feature grid
- Process walkthrough
- Conversion CTA

### ⚡ Performance Principles
- No external UI frameworks
- Minimal runtime logic
- Native CSS transitions
- Inline SVG icons
- Zero analytics footprint
