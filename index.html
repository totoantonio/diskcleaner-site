Technical Specs

Everything under the hood.

Compatibility, real performance numbers, privacy details, and system requirements.

System Requirements

Built with SwiftUI APIs requiring macOS 13 Ventura minimum. Fully tested through macOS 26 Tahoe.

macOS Compatibility
macOS 26 Tahoe ✓Sequoia 15Sonoma 14Ventura 13

Monterey 12 and earlier not supported — missing required SwiftUI APIs

Chip Support — Universal Binary
  • Apple M4 (ARM 64-bit) — native
  • Apple M3 (ARM 64-bit) — native
  • Apple M2 (ARM 64-bit) — native
  • Apple M1 (ARM 64-bit) — native
  • Intel x86 64-bit — native
Distribution
  • ~5 MB install size
  • Apple-notarized — passes Gatekeeper
  • Not sandboxed — required for Library access
  • Direct download from diskcleaner.pro
  • Single-user per-device license

Scan Speed

All file I/O runs on Task.detached background threads. Scans target known folder paths — not full disk enumeration. Speed depends on cache size, not filesystem format.

Quick Scan — all 7 categories, depth 3< 10s
Deep Scan — small DerivedData10–20s
Deep Scan — large DerivedData (~20 GB)20–45s
Deep Scan — very large caches (50 GB+)45–90s

Tested on Apple Silicon SSD. Scans are cancellable mid-flight with no side effects.

Built With

100% native Apple frameworks. No Electron, no web views, no third-party UI libraries.

Core Stack
  • SwiftUI — native macOS UI framework
  • Swift 6 — full concurrency compliance
  • AppKit — menu bar, haptics, NSWorkspace
  • StoreKit 2 — license management
Concurrency Architecture
  • Task.detached — all file I/O off main thread
  • async/await + @MainActor — clean UI updates
  • Task.isCancelled — mid-flight scan cancellation
  • @Published — live animated size updates
Safety Architecture
  • FileManager.trashItem() — never removeItem()
  • 20+ protected folder blocklist checked pre-scan
  • Bundle ID read from Info.plist for accurate matching
  • Screenshot path from com.apple.screencapture.plist

Privacy

Your data never leaves your Mac. Scanning reads only file metadata — names and sizes, never content.

  • Zero network activity during scanning or cleaning
  • No analytics, no telemetry, no crash reporting
  • No account required — ever
  • License activation is the only outbound network call
  • No background processes when app is closed
  • Requires Full Disk Access — explicitly granted by you
  • All data stays on your Mac
