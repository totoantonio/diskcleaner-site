What Gets Cleaned — and What's Safe

DiskCleaner is built around a review-first, Trash-first workflow. It focuses on clutter macOS and apps regenerate automatically, then marks larger or riskier areas for closer review before anything moves.

Quick Scan coverage

  • App Cache — Temporary app cache files that rebuild as needed.
  • Browser Cache — Cache data from supported browsers and profiles. Safari cache is measured but not cleared. Passwords, bookmarks, and history stay untouched.
  • Screenshots — Old screenshots that tend to accumulate unnoticed on long-used Macs.
  • Trash — Files you already threw away that are still consuming space.
  • System Logs — Diagnostic and crash logs that are useful temporarily but rarely worth keeping forever.
  • Developer Data — Xcode DerivedData, Archives, Device Support, simulators, SwiftPM, CocoaPods, npm, JetBrains, and VS Code caches.
  • App Leftovers — Support files and residue left behind after apps were removed.

Deep Scan and expanded review areas

Deep Scan goes beyond the everyday clutter pass and surfaces larger storage categories that often need more deliberate review.

  • Downloads — Useful for catching forgotten installers, archives, and exported files.
  • iOS backups — Old device backups that can consume tens of gigabytes.
  • Mail Attachments — Attachment caches, including expanded support for Outlook, Spark, and Canary locations.
  • External drive review — Additional clutter visibility beyond the startup disk.
  • Caution-labeled items — Results that deserve a second look before cleanup.

What DiskCleaner does not do for you automatically

  • It does not silently delete files in the background.
  • It does not permanently delete as part of normal cleanup. Files go to macOS Trash.
  • It does not clear personal content like passwords, bookmarks, or saved logins.

What DiskCleaner never targets as cleanup junk

  • Documents, spreadsheets, or any file in your home folder outside of Library/
  • Photos, videos, or music libraries
  • App preferences and settings (~/Library/Preferences)
  • Keychain data or passwords
  • iCloud Drive files
Tip: DiskCleaner shows every file before anything moves. Use the checkboxes and caution labels to keep high-confidence cleanup fast and everything else deliberate.

How to Use DiskCleaner

Running your first clean

  1. Open DiskCleaner and start with Quick Scan for the most common clutter categories.
  2. Review the results list. DiskCleaner shows categories, file sizes, and per-file checkboxes before anything moves.
  3. If you want deeper coverage, switch to Deep Scan to include larger review areas such as Downloads, iOS backups, Mail attachments, and external-drive findings.
  4. Pay attention to notes, legends, and caution labels. Those are there to slow you down on categories where context matters.
  5. Click Clean when you are satisfied with the selection. Files move to Trash, not permanent deletion.

Understanding Quick Scan vs Deep Scan

Quick Scan is the fast everyday pass. Deep Scan expands into larger, more review-sensitive storage areas. The best default workflow is to run Quick Scan regularly and use Deep Scan when storage pressure is real or you need a broader audit.

Menu bar utilities

DiskCleaner includes menu bar utilities so disk state is always close at hand. The menu bar view is useful for quick visibility into available space and for returning to the app quickly when storage pressure starts building.

Using RAM Optimizer

The latest update adds a dedicated RAM Optimizer view with live metrics for Memory Pressure, Compressed Memory, Swap Used, and Page In/Out (Min). Use Optimize when memory pressure is elevated and you want a safe refresh without digging through Activity Monitor first.

Using the Uninstaller

Open App Uninstaller when dragging an app to Trash is not enough. DiskCleaner helps you review the app bundle plus leftover support files before removal, and the latest uninstaller update improves layout, drag-and-drop flow, and installed-app selection.

Free scans and Pro unlock

Troubleshooting Common Issues

DiskCleaner shows 0 MB found

This is normal on a freshly cleaned or new Mac. macOS caches rebuild as you use your apps — try scanning again after a day of normal use.

macOS asks for Full Disk Access or my password — is that normal?

Yes. Some categories involve locations macOS protects more aggressively. Depending on what you review and choose to clean, macOS may require Full Disk Access or standard administrator approval. DiskCleaner uses the normal macOS permission flow and does not ask you to bypass it.

An app is slow after cleaning

Apps may feel slightly slower the first time they launch after their cache is removed — this is expected. Performance returns to normal within a minute as the cache rebuilds. If an app continues to behave oddly, restarting it or your Mac usually resolves it.

Disk space didn't change much after cleaning

macOS does not always reflect reclaimed space instantly. Some recovery may appear as purgeable before it shows up as fully available. If the number looks slow to update, wait a moment and then recheck, or restart the Mac if storage reporting still looks stale.

DiskCleaner can't be opened (Gatekeeper warning)

If macOS shows "DiskCleaner cannot be opened because it is from an unidentified developer," go to System Settings → Privacy & Security, scroll down, and click Open Anyway next to the DiskCleaner entry.

The Uninstaller doesn't show what I expected

Use the improved installed-app picker first, then try the drag-and-drop uninstall flow if needed. Some apps may have fewer matchable leftovers than others, and App Store-distributed apps can behave differently because of macOS sandboxing.

Deep Scan found categories I want to keep

That is exactly what the review model is for. Deep Scan is broader by design, and some categories are intentionally marked for second-look review. Uncheck anything you want to keep and clean only the categories you are confident about.

Keyboard Shortcuts

DiskCleaner supports core macOS app shortcuts such as closing windows, hiding the app, quitting the app, and standard text-editing shortcuts in text fields. The table below stays intentionally focused on reliable, app-wide shortcuts.

Common macOS shortcuts

ActionShortcut
Hide DiskCleaner⌘ H
Quit DiskCleaner⌘ Q
Close the current window⌘ W

Text fields

Standard macOS text-editing shortcuts such as ⌘A, ⌘C, ⌘V, and ⌘Z work anywhere DiskCleaner provides a normal text field.

Note: If a shortcut is not shown in the app’s menus, do not rely on it as part of your workflow yet.
